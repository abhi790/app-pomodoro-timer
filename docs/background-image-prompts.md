# Background image prompts

These prompts create the pictures behind the healthy tips on the Force Break screen. There are 7 categories and 4 pictures per category, 28 pictures in total.

## How to use

1. Open an image generator (for example ChatGPT) and paste one prompt at a time. Every prompt is complete, so you can use it on its own.
2. Ask for a wide 16:9 landscape picture. If the tool gives a slightly different wide shape (for example 1792x1024), that is fine, the app crops the picture to fit each monitor.
3. Check the result: no text, no letters, no faces, and a calm, darker middle. If not, ask for a new version.
4. Save it as a JPG (quality about 85, under 1 MB) with the file name written above the prompt.
5. Put it in the matching folder:

```
src/pomodoro/assets/backgrounds/<category>/<file name>
```

For example `src/pomodoro/assets/backgrounds/water/water_01.jpg`.

Tip: make the first picture, and if you like the style, keep using the same chat for the rest so the whole series looks alike.

## The shared style

Every prompt below already starts with this text:

> Premium calm wellness wallpaper in wide 16:9 landscape format, highest resolution available. Soft minimal illustration with smooth color gradients and gentle glowing light, slightly painterly, realistic soft depth of field, subtle fine film grain, no harsh outlines. Dark, moody, low-contrast tones so that big white text placed on top stays easy to read. COMPOSITION RULE: place the main subject in the left third or the right third of the frame, or as a large soft shape in a corner. Keep the central 50 percent of the picture calm, simple, slightly darker and with very little detail, because a huge clock and a sentence of text will sit there. Soft vignette on the edges. STRICT RULES: no text, no letters, no numbers, no logos, no brand names, no watermark, no user interface, no frames or borders, no human faces (silhouettes seen from far away or from behind are fine). The look must feel peaceful, clean and premium, and it must match one single art style across the whole series of 28 pictures.
